# SALC-NOTES-TEMPLATE-DEMO
Este template serve de modelo para caso você queria montar um sistema de central de arquivos, serve para Imagens, Vídeos, Documentos (PDF) etc.. uso atualmente o  https://supabase.com/ como serviço de hospedagem, e o SALC-NOTES serve para mim como uma solução de diretórios para meu SIGECON, criando uma interface facilitada para usuários, podendo importar notas e baixar posteriormente, de modo mais prático e leve do que outros serviços, no meu caso atualmente uso para repositório de notas de de uso convencional da administração pública no ambito do 3 Batalhão de Suprimento do Exército Brasileiro, todos os dados são de acesso público pelo Portal da Transparência caso queria consultar, (este sistema visa facilitar a vida dos militares e das informações pertitentes ao trabalho da (Seção de Aquisição Licitações e Contratos - SALC) onde lidamos com milhares de informações e se torna mais prático filtrar e centralizar as que mais precisamos.
